# Brand assets (proposal)

Proposal only; the owner signs off logos.

- `logo.svg` / `logo-dark.svg`: 64x64 mark. A rounded square holding a three-tier pine built from one polygon (three stacked triangles), a 6x5 trunk rectangle, and a circle cut-out at the centre tier that reads as a price-tag hole. Flat fills, no strokes, legible at 16 px.
- `wordmark.svg`: mark plus `pinetree-solari` / `demo / pricing ledger` in a monospace stack (`Noto Sans Mono, ui-monospace, ...`). Text is live, not outlined.
- `*-preview.png`: resvg renders (`resvg -w 840 --background '#F6F8F4' wordmark.svg wordmark-preview.png`), optimised with oxipng.

Colours: pine `#1F5A41`, paper `#F6F8F4`, ink `#14231C`; dark mode mint `#6FCF9A` on `#0E1512`. See `DESIGN.md`.
